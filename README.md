# AI Engineering Demos & Architecture Repository

Welcome to this repository! This codebase contains a collection of **AI Engineering demonstrations, Spec-Driven Development workflows, and production-style agentic architectures**. It is published publicly so technical recruiters, engineering leads, and peers can read, review, and understand how modern enterprise AI systems are designed and built.

## 📌 Included AI Engineering Demos

Below is an overview of the AI engineering demos, protocols, and frameworks featured in this repository *(update the folder names to match your exact directory layout)*:

* **Agentic Workflows & Orchestration (`./agentic-workflows`)** – Demonstrates autonomous goal-driven agents, multi-step planning, memory management, reflection loops, and complex task orchestration.
* **Model Context Protocol (MCP) (`./mcp-demos`)** – Implements standardized MCP servers and clients that securely connect AI agents and LLMs to external APIs, databases, and enterprise tools.
* **Agent-to-Agent (A2A) Protocol (`./a2a-protocol-demos`)** – Showcases interoperable multi-agent communication, task delegation, and cross-agent collaboration using the A2A standard.
* **Agent Development Kit (ADK) (`./adk-demos`)** – Demonstrates modular agent construction, tool integration, and lifecycle orchestration using ADK.
* **LangChain4j Enterprise Integrations (`./langchain4j-demos`)** – Java-native LLM and agentic integrations featuring RAG pipelines, embedding stores, chat memory, and structured AI services.
* **Spec-Driven Development (SDD) (`./spec-driven-development`)** – Demonstrates structured AI-assisted software engineering using formal specifications, requirements-to-code pipelines, and automated verification.
* **AWS Kiro Agentic IDE Workflows (`./aws-kiro-demos`)** – Showcases spec-first development, automated task execution, and agentic hooks built with AWS Kiro.
* **GCP Antigravity Development (`./gcp-antigravity-demos`)** – Explores cloud-native AI development and agentic orchestration workflows using Google Cloud Antigravity.
* **Additional AI Engineering Prototypes (`./more-ai-demos`)** – Includes supplementary experiments covering vector search, safety guardrails, and LLM evaluation.
